##  影视仓库 (yscku.com)
影视聚合资源仓库，整理电影、剧集、动漫、综艺、短剧等影视元数据，站点：[https://www.yscku.com](https://www.yscku.com)
##  项目介绍

影视仓库是影视元数据聚合整理项目，汇集海量影视条目，覆盖院线电影、国产剧集、经典动漫、真人秀综艺、网络短剧，实时同步站点更新数据，可用于影视爬虫、影视前端演示、播放壳配置参考。

站点每日更新数百部作品，包含热榜、追剧周表、专题合集，包含剧集集数、更新状态、简介、海报封面信息，分类齐全，内容持续维护更新。

## 📦 内容覆盖

- 🎬 电影：院线正片、犯罪、剧情等各类影片元数据与简介
- 📺 电视剧：国产剧集、历史革命剧，标记更新集数 / 完结状态
- 🎞️ 短剧：腾讯等平台精品网络短剧，记录集数与完结信息
- 🎮 动漫：动态漫、3D 国漫，记录连载、更新集数
- 📻 综艺访谈：真人秀、调解访谈、户外综艺，同步播出期号
- 📅 追剧周表：按星期标记更新时间，new 标记最新上新内容
- 📚 专题合集：系列剧、晚会等专题分类索引
